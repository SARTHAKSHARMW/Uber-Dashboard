🚖 Uber Demand Analysis & Prediction Dashboard

📊 Overview
This project analyzes Uber ride data and predicts demand patterns using machine learning.

 🚀 Features
- 📈 Exploratory Data Analysis (EDA)
- ⏰ Time-based insights (hour, day, month)
- 📍 Location-based visualization
- 🤖 Demand Prediction using Random Forest
- ⚡ Surge Pricing Simulation
- 🌐 Interactive Streamlit Dashboard

 🧠 ML Models Used
- Linear Regression (baseline)
- Decision Tree
- Random Forest (final model)
